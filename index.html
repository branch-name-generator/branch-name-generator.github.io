    How it works
    
        
    The title is transliterated (Ukrainian and Russian included), lower-cased, and everything except letters and digits becomes a separator. The issue number goes in front, so “1234” and “Fix login bug” give 1234/fix-login-bug. Everything runs in your browser; nothing you type is sent anywhere.
    

        
    FAQ
    
        
    
          Which characters are not allowed in a Git branch name?
          
    Spaces, ~ ^ : ? * [ \, the sequences “..” and “@{”, a leading “-”, a trailing “.” or “/”, and path parts ending in “.lock”. The generator removes all of them.
    
        
    
        
    
          Can I paste an issue link?
          
    Yes. Links from GitHub, GitLab, Jira and Linear are reduced to the issue key (for example PROJ-123).
    
        
    
        
    
          Why does the commit command use single quotes?
          
    In bash and zsh single quotes stop $, backticks and ! in the title from being interpreted. On Windows PowerShell, edit the quoting.
    
        
    
        
    
          Are my settings saved?
          
    The base branch, prefix and other settings are kept in this browser’s local storage. The fields themselves are kept in the page address, so you can bookmark them.
